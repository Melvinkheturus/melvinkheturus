## 💫 About Me

I am a **Full Stack Software Engineer** with an entrepreneurial mindset and a strong foundation in **UI/UX Design**. My approach blends user-centric design principles with scalable software architecture to build production-grade web applications and AI-driven business tools.

- 🎓 **Education**: BCA Graduate (2025)
- 🎨 **Design Foundation**: Trained in UI/UX Design at **Zukun Academy**, emphasizing user research & visual hierarchy.
- 💼 **Professional Experience**: Full Stack Software Developer at **Dutuk** (Mobile & Web Ecosystems).
- 🏢 **Entrepreneurship**: Founder & Lead Engineer at **MergeX** — an AI and software development firm building custom SaaS, CRM systems, and automated workflows.
- 📍 **Location**: Chennai, India 🇮🇳
- 🎯 **Career Goal**: Collaborating with fast-paced engineering teams, shipping impactful software, and continuously mastering modern web & AI architectures.

## 📐 Engineering Philosophy & Standards

```
  ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
  │  User Experience│ ────> │  Architecture   │ ────> │ High Speed &    │
  │  & Product Design│       │  & Scalability  │       │ Zero Friction   │
  └─────────────────┘       └─────────────────┘       └─────────────────┘
           │                         │                         │
           ▼                         ▼                         ▼
   Trained UI/UX Eye        Clean TypeScript Code     Optimized Database &
   Frictionless Flow         Modular Design Pattern    Sub-100ms API Response
```

- 🎯 **Product-First Engineering**: Software exists to solve real human and business problems. Code is written with clarity, end-user clarity, and maintainability in mind.
- ⚡ **Performance & Simplicity**: Fast page loads, minimal bundle sizes, and thoughtful micro-interactions keep users engaged.
- 🛡️ **Scalable Architecture**: Strict TypeScript typing, modular directory layouts, and structured Git commit messages (`feat:`, `fix:`, `refactor:`).
